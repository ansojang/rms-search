업그리드 계산기

최저 매수가·최대 매도가·전체 시드를 넣으면, 회차끼리 겹치지 않게(익절가 < 다음 회차 매수가) 차시별 매수간격·매도간격·회차당 수량과 전체 익절 시 순수익을 계산합니다.

입력

계산 규칙
매도간격 = 매수간격 − 1호가 → 익절가가 항상 다음 회차 매수가보다 1호가 낮음.
시드를 모든 회차에 나눠 배정(전 회차 주문금액 합계 ≤ 시드, 수량 동일) → 꺾여도 마지막 회차 1개분만 물림.
목표 수익률 = 최저 매수가에 시드 전부 매수 → 상단 매도가에 전부 매도했을 때의 수익률(이론 최대).

호가 단위는 최대 매도가 구간 기준으로 맞춥니다 (2,000원 미만 1원 · 5,000 미만 5원 · 2만 미만 10원 · 5만 미만 50원 · 20만 미만 100원 · 50만 미만 500원 · 이상 1,000원, 코스피·코스닥 동일).

결과

① 전체 시드, ② 상단 매도가격, ③ 하단 매수 시작가격을 입력하고 계산하기를 누르면 회차 수, 회차당 수량, 매수·매도간격과 예상 수익이 여기에 나옵니다.

시드 분산 결과 — 3·5·10회차 중 하나를 누르면 아래 내용이 바뀝니다

상단까지 전 회차 매도 시

3 · 5 · 10회차 비교 — 행을 누르면 아래에 회차표가 나옵니다

차시매수간격매도간격회차당 수량총 매도금액예상 순수익예상 수익률목표 대비1회 평균 익절최대 물림(1회차분)

회차표

회차매수가매도가다음 회차 매수가수량주문금액매도금액익절 순수익누적 순수익

업그리드: 순환 끔, 각 회차는 한 번 익절하면 매수 중지. 회차가 겹치지 않으므로 상승 중 꺾여도 마지막에 매수한 1개 회차만 보유합니다. 수수료: 한국투자증권 기준 매수 0.015% · 매도 0.015% · 증권거래세 0.20%(코스피·코스닥 동일)를 차감한 순수익입니다. 과거 데이터 기반 참고 자료이며, 종목 추천이나 수익 보장이 아닙니다.
